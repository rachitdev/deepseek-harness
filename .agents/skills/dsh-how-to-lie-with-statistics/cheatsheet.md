# Cheat Sheet — How to Lie with Statistics

## THE FIVE QUESTIONS (Chapter 10 — use these first, in order)

| # | Question | Hunting for | Fastest tell |
|---|---|---|---|
| **1** | **Who says so?** | conscious bias, unconscious bias, borrowed authority | interested party; "the survey shows"; an O.K. name printed *alongside* the conclusion rather than standing behind it |
| **2** | **How does he know?** | sampling method and adequacy | self-selected sample; unreported response rate; no n; a correlation from too few cases |
| **3** | **What's missing?** | n, error term, range, base, comparison, causal factor | unqualified "average"; percentage with no raw count; index with no base period |
| **4** | **Did somebody change the subject?** | substitution between raw figure and conclusion | reported cases for cases; saying for doing; component cost for total; one base for another; *post hoc* |
| **5** | **Does it make sense?** | unproved assumptions, face-absurdity | impossible implied totals; spurious decimals; naive extrapolation; contradicts your own observation |

**Mnemonic order:** source → method → omissions → substitution → plausibility.

## Tells and smells (symptom → diagnosis → fix)

| Symptom | Diagnosis | Fix |
|---|---|---|
| "Average" with no qualifier, on money | mean/median swap (Ch 2) | demand which; ask *average of what, who's included* |
| Surprisingly precise **and** improbably flattering | fabricated or self-reported sample (Ch 1) | ask how it could possibly have been measured that finely |
| Big percentage, no n | tiny sample; possibly 2 of 41 (Ch 3, 9) | multiply back to raw counts |
| Percentage improvement, no control group | Doakes' toothpaste method (Ch 3) | ask how many trials were run and filed |
| Chart line climbing steeply | truncated axis (Ch 5) | check the zero line; recompute % from labels |
| Chart with no numbers on the axis | unauditable by design (Ch 3) | discard |
| Objects drawn at proportional heights | one-dimensional picture (Ch 6) | cube the height ratio to see what the eye received |
| Shaded map | area encoding a non-area variable (Ch 9) | build the opposite-leaning selection from the same data |
| "26 per cent more" | missing comparator (Ch 7) | ask *more than what?* |
| Lab result offered as a health claim | semi-attached figure (Ch 7) | ask "So what?" |
| Counts compared across years or places | exposure changed (Ch 7) | get the rate: per passenger-mile, per person at risk |
| Disease/crime figures jump | reporting artefact (Ch 7, 10) | check definition, diagnosis, legal requirement, incentive; cross-check deaths |
| Correlation stated as cause | post hoc (Ch 8) | run chance / reverse / third factor / trend of the times |
| Older group differs from younger | cohort effect (Ch 8) | demand longitudinal or equivalent-group data |
| Discounts or cuts and raises combined | shifting base (Ch 9) | name every base; compound, never add |
| Percentage increases summed | bogus addition (Ch 9) | if each component rose ~10%, the total rose ~10% |
| "Rose three percentage points" / "rose 100 per cent" | percentage vs percentage points (Ch 9) | make the speaker state both |
| Trend line extended into the future | uncontrolled extrapolation (Ch 10) | surface the silent clauses: "everything else being equal," "present trends continuing" |
| Two competing "firsts" | firsters (Ch 10) | ask *first in what category, chosen by whom* |
| "Six per cent" on a loan | declining balance vs on-the-dollar (Ch 10) | £6 on the £100 repaid monthly ≈ 12% real; over six months ≈ 48% |

## Thresholds and default values

| Quantity | Value | Source |
|---|---|---|
| Minimum acceptable significance, most purposes | **5 per cent** (19 chances in 20) | Ch 3 |
| "Practically certain" | **1 per cent** (99 chances in 100) | Ch 3 |
| Probable error coverage | **exactly half** the cases | Ch 4 |
| Standard error coverage | **about two-thirds** of the cases | Ch 4 |
| Revised Stanford-Binet probable error | **3 per cent** (e.g. IQ 98 ± 3) | Ch 4 |
| "Normal" IQ, read as a band | **90 to 110**, not 100 | Ch 4 |
| Typical high response rate, mail questionnaire | "a five or ten per cent response is quite high" | Ch 1 |
| Census family-income precision example | 19 chances in 20 of being within **±$71** | Ch 2 |
| Rise needed to reverse a 20% cut | **25 per cent** | Ch 9 |
| Rise needed to reverse a 50% cut | **100 per cent** | Ch 9 |
| Stacked discounts "50% and 20% off" | **60 per cent** off, not 70 | Ch 9 |

## Averages: selection matrix

| Data shape | Use | Because |
|---|---|---|
| Approximately normal (heights, most physical traits) | any — mean, median and mode coincide | bell curve |
| Skewed (incomes, wealth, firm size, house prices) | **median**, named as such | mean is dragged by the long tail; "nearly everybody is below average" |
| "What is the typical case?" | **mode** | most frequently met-with value |
| Ratios and rates being indexed | consider the **geometric mean** | milk ×0.5, bread ×2 → √(50×200) = 100, no change |
| Any published money average | reject until qualified | the omission is the manipulation |

**The four questions for a family/household figure (Ch 2):** what kind of average · what "family" means · who says so and how he knows · how accurate it is.

## Charts: honest vs dishonest

| Element | Honest | Dishonest |
|---|---|---|
| Vertical axis on a chart of levels | reaches zero | truncated, break unmarked |
| Axis break | visible gap or jog, labelled | "with no gap or other indication to warn you" |
| Aspect ratio | proportionate | ordinate rescaled for drama |
| Bar widths | constant | vary with length |
| Pictograph units | identical icon, repeated; count varies | one icon resized in height |
| Objects with implied depth | avoid, or use flat bars | moneybags, furnaces, human figures, cows |
| Two valid methods disagree | show both on one chart (*Time*) | show the flattering one |

**Cube-law table** — height ratio drawn → what the reader receives:

| Height ×1.5 | ×2 | ×3 |
|---|---|---|
| area 2.25, volume **3.4** | area 4, volume **8** | area 9, volume **27** |

## Correlation triage (Ch 8)

| Step | Question | If yes |
|---|---|---|
| 1 | Could this be chance in a small sample? | demand replication; ask how many pairs were tested |
| 2 | Could the arrow run the other way? | state both stories; neither is proved |
| 3 | Is there a plausible third factor? | name it (age, income, house size, price level) |
| 4 | Are both series just following the trend of the times? | detrend or find a divergent period |
| 5 | Is the claim inside the observed range? | if not, refuse the extension (rain and corn) |
| 6 | Is this being applied to one individual? | "almost worthless in determining action in any single case" |

Correlation types: **chance** · **real, direction unknown** · **real, neither causes the other**.

## Percentage discipline (Ch 9)

1. Name the base. Every time.
2. Never add percentage increases across components.
3. State whether profit is figured on **cost** or on **selling price** — "you are obligated to indicate which you are using." ($1.75 cost, $40 price = 2,185% on cost, 95.6% on selling price, *not* 3,800%.)
4. A cut and a raise use different bases: 20% cut then 5% raise returns one-**fifth**, not one-fourth.
5. Percentage points ≠ per cent.
6. With small n, publish the count, not the percentage.
7. Check the decimal point. ".34 per cent" vs "34 per cent" — Lord Randolph's "damned little dots."

## Index numbers: the three answers from one dataset

Milk 10p → 5p; bread 10p → 20p.

| Method | Result |
|---|---|
| Arithmetic mean, **last year** = 100 | prices **up 25%** |
| Arithmetic mean, **this year** = 100 | prices were **25% higher** before |
| **Geometric** mean, either base | **no change** |

Always demand: base period, averaging method, basket composition.

## Audit pipeline for any statistic

```
1. RESTATE      What exactly was counted, of whom, when, by whom?
2. SOURCE       Who benefits from this number? Conscious or unconscious bias?
                Does the O.K. name stand behind the conclusion or beside it?
3. SAMPLE       Universe → frame → sample. Who could not be in it?
                Response rate? Self-selected? n large enough for the effect size?
4. MEASURE      Which average? What range? What error term? What base?
                Raw counts behind every percentage.
5. PICTURE      Zero line? Axis labels? Icon resized? Map encoding area?
6. JOIN         Does the measured thing entail the claimed thing? "So what?"
                Counts or rates? Comparable groups? Reporting rules unchanged?
7. CAUSE        Chance / reverse / third factor / trend of the times.
                Inside the observed range? Applied to a group or an individual?
8. SANITY       Round the precision back. Compute implied totals.
                Does it survive contact with what you can see?
9. VERDICT      Sound · unusable · cannot tell. "Cannot tell" is a real answer.
```
