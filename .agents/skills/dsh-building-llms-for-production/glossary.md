# Glossary — Building LLMs for Production

**Action Agent** — Agent that decides and executes a single action at a time; suited to simple tasks (Ch 9)
**Activation Pruning** — Removing redundant activations at inference time; requires dynamic runtime identification (Ch 11)
**AIMessagePromptTemplate** — LangChain template for an assistant turn, used to demonstrate desired style in chat few-shot (Ch 6)
**Alignment** — Making model outputs match human expectations for accuracy, safety, and helpfulness (Ch 3, 10)
**Answer Relevancy** — Ragas metric: how well a response addresses the query's intent, independent of faithfulness (Ch 8)
**AutoGPT** — Open-source autonomous agent: internet-connected, self-prompting, task-executing, with external file-based memory (Ch 9)
**AWQ (Activation-aware Weight Quantization)** — PTQ method protecting the 0.1–1% of weight channels with the largest activations, by scaling before uniform quantization (Ch 11)
**BabyAGI** — Autonomous agent loop of four sub-agents: Execution, Task Creation, Prioritization, Context (Ch 9)
**BatchEvalRunner** — LlamaIndex class running multiple evaluators over many queries concurrently (Ch 8)
**Beam Search** — Decoding method exploring several candidate sequences in parallel and keeping the highest-scoring (Ch 3, 11)
**BFloat16** — 16-bit float format; `bf16=True` reduces fine-tuning memory (Ch 10, 11)
**BitsAndBytes** — Library providing 4-bit and 8-bit quantized model loading (Ch 10, 11)
**Chain** — LangChain composition of model, prompt, memory, output parsing, and debugging into one interface (Ch 5, 7)
**Chain-of-Thought (CoT)** — Prompting the model to produce intermediate reasoning before the answer (Ch 4, 8)
**Chat Engine** — LlamaIndex conversational interface over data — a series of queries and responses (Ch 8)
**Chinchilla Scaling Law** — Compute-optimal training relationship between model size and training tokens (Ch 1)
**Chunk Overlap** — Characters shared between consecutive chunks so context is not severed at boundaries (Ch 7)
**CommaSeparatedListOutputParser** — Zero-configuration parser for flat comma-separated lists; cannot carry reasoning (Ch 6)
**Cohere Rerank** — Endpoint that re-scores and reorders retrieved documents by relevance; complements, does not replace, search (Ch 8)
**ConstantLengthDataset** — TRL class packing samples to a fixed `seq_length`, optionally infinite (Ch 10)
**Constitutional AI** — Anthropic method aligning a model against a written set of principles rather than human labels (Ch 3, 9)
**Context Precision** — Ragas metric: how much of the retrieved context is actually relevant (Ch 8)
**Context Recall** — Ragas metric: how much of the needed context was successfully retrieved (Ch 8)
**Context Window** — Maximum tokens a model can attend to in one request (Ch 1, 7)
**ContextualCompressionRetriever** — LangChain retriever wrapping a base retriever with a DocumentCompressor (Ch 7)
**Conversational Chain** — Chain with `ConversationBufferMemory` tracking prior turns (Ch 7)
**Correctness** — RAG metric comparing a generated answer to a reference answer; requires labels (Ch 8)
**Cosine Similarity** — Distance metric measuring the angle between two vectors; the default for embedding search (Ch 7)
**Decoder-only** — Transformer category generating text autoregressively; the GPT/LLaMA/OPT family (Ch 2)
**Deep Lake** — Activeloop's multi-modal vector store and deep-learning database, supporting streaming, versioning, and hybrid queries (Ch 5, 7)
**Deep Memory** — Activeloop feature adapting the embedding space to your data using LLM-generated questions per chunk; ~25% recall improvement (Ch 9)
**DPO (Direct Preference Optimization)** — RLHF alternative optimizing directly with binary cross-entropy, no reward model, no RL loop (Ch 10)
**Double Quantization** — QLoRA technique quantizing the quantization constants themselves (Ch 10, 11)
**Dynamic Quantization** — Quantization applied at runtime to activations; the preferred approach for transformers (Ch 11)
**Emergent Abilities** — Capabilities appearing at scale that were absent in smaller models (Ch 1)
**Encoder-decoder** — Transformer category mapping an input sequence to an output sequence; T5, BART (Ch 2)
**Encoder-only** — Transformer category producing representations; BERT (Ch 2)
**Example Selector** — Component choosing which few-shot demonstrations to include per query (Ch 6)
**Faithfulness** — Whether a response is grounded in the retrieved context, free of fabrication (Ch 8)
**FaithfulnessEvaluator** — LlamaIndex evaluator returning a boolean `passing` for groundedness (Ch 8)
**FAISS** — Facebook similarity-search library used as in-memory vector store for AutoGPT/BabyAGI memory (Ch 9)
**Few-Shot Prompting** — Supplying worked examples in the prompt so the model infers the task and style (Ch 4, 6)
**FewShotPromptTemplate** — LangChain template combining examples (or a selector), example prompt, prefix, suffix, and separator (Ch 6)
**Fine-Tuning** — Resuming training on task-specific data to adapt a pre-trained model (Ch 3, 10)
**FnRetrieverOpenAIAgent** — LlamaIndex agent that retrieves its own tools from an ObjectIndex (Ch 9)
**FunctionTool** — LlamaIndex wrapper turning a Python function into an agent tool, using annotations and docstring as its description (Ch 9)
**Function Calling** — Model capability of returning a function name plus arguments rather than prose (Ch 9)
**generate_question_context_pairs** — LlamaIndex utility building a synthetic evaluation dataset from nodes (Ch 8)
**Golden Context Dataset** — 177 curated query/source pairs with ideal answers, used as a precision benchmark (Ch 8)
**GPTQ** — PTQ method quantizing layer by layer to minimize MSE; mixed int4-fp16, needs a calibration dataset (Ch 11)
**Gradient Checkpointing** — Storing fewer activations and recomputing them, trading compute for memory (Ch 10)
**Guideline Adherence** — RAG metric checking a response against stylistic, factual, and ethical criteria (Ch 8)
**Guanaco** — Model family produced by QLoRA fine-tuning, showing strong results at small size (Ch 10)
**Hallucination** — Model output that is fluent but unsupported by fact or provided context (Ch 3, 7)
**Harmfulness** — Ragas critique metric scoring generation of harmful or inappropriate content (Ch 8)
**Hit Rate** — Retrieval metric: frequency with which a relevant item appears in the top results (Ch 8)
**Hybrid Search** — Combining keyword lookup with embedding search for specificity plus context (Ch 8)
**Inception Prompting** — CAMEL technique keeping role-playing agents aligned with the original human intent (Ch 9)
**Index** — Data structure organizing stored data for efficient search; in LangChain, usually vector-database-backed (Ch 7)
**Inference API** — Hugging Face's free, rate-limited hosted inference over 150,000+ models; not for production (Ch 9)
**Instruction Fine-Tuning** — Training a model to read prompts as instructions rather than text to complete; popularized by InstructGPT (Ch 10)
**Intel Neural Compressor** — Open-source library for quantization, pruning, and distillation with accuracy-driven tuning (Ch 11)
**KL Divergence Penalty** — RLHF constraint keeping the tuned model's token distribution near the original's (Ch 10)
**Knowledge Graph** — Graph of entities and their relations, e.g. `<Fabio, lives in, Italy>` (Ch 6)
**Knowledge Retrieval (Assistants API)** — OpenAI-hosted RAG: uploaded documents are segmented, indexed, embedded, and vector-searched (Ch 9)
**LangChain Hub** — Repository of community prompts with versioning and a playground (Ch 8)
**LangSmith** — Platform for debugging, testing, evaluating, and monitoring LLM applications (Ch 8)
**LengthBasedExampleSelector** — Selector including fewer examples for long queries to respect a token budget (Ch 6)
**LIMA** — "Less Is More for Alignment": 1,000 curated samples via SFT as a possible replacement for RLHF (Ch 10)
**Lit-GPT** — LightningAI tool applying LoRA without manual architecture edits (Ch 10)
**LLM.int8()** — Quantization method keeping activation outliers in higher precision (Ch 11)
**LLMChainExtractor** — DocumentCompressor using an LLMChain to keep only query-relevant statements (Ch 7)
**LoRA (Low-Rank Adaptation)** — Fine-tuning by training small low-rank update matrices added to frozen weights, typically in attention layers (Ch 10)
**Lottery Ticket Hypothesis** — Large random networks contain 10–20%-size subnetworks that, trained from their original initialization, match or beat the full network (Ch 11)
**map_reduce** — Chain type summarizing each document separately, then combining the summaries (Ch 7)
**MAP (Mean Average Precision)** — Retrieval metric averaging precision after each relevant document, across queries (Ch 8)
**Memory Stream** — Generative Agents' chronological database of an agent's experiences (Ch 9)
**MetadataReplacementNodePostProcessor** — LlamaIndex component swapping a matched sentence for its surrounding window (Ch 8)
**Mixed-Precision Quantization** — Assigning higher bit precision to more important layers to limit accuracy loss (Ch 11)
**MRR (Mean Reciprocal Rank)** — Retrieval metric rewarding placement of the most relevant result at the top (Ch 8)
**NDCG** — Normalized Discounted Cumulative Gain; rewards relevant documents ranked early, normalized so query sets compare (Ch 8)
**NF4 (4-bit NormalFloat)** — QLoRA data type using quantile quantization, optimal for normally distributed weights (Ch 10, 11)
**Node** — LlamaIndex unit of indexed content, produced by a node parser from Documents (Ch 8)
**ObjectIndex** — LlamaIndex wrapper making tools themselves retrievable via a VectorStoreIndex (Ch 9)
**ONNX** — Standardized model format for interoperability and efficient CPU execution (Ch 11)
**OpenAI Assistants API** — Hosted agent service with Code Interpreter, Knowledge Retrieval, and Function Calling (Ch 5, 9)
**Optimum** — Hugging Face library bridging transformers/diffusers to hardware-optimized runtimes (Ch 11)
**Output Parser** — Component defining and enforcing the data structure expected from a model (Ch 6)
**OutputFixingParser** — Repair parser that sees only the malformed output; fixes wrong keys, fails on missing ones (Ch 6)
**Paged Optimizers** — QLoRA technique absorbing memory spikes during training (Ch 10)
**PEFT** — Parameter-Efficient Fine-Tuning library: LoRA, Prefix Tuning, P-tuning (Ch 10)
**PeftModel** — Wrapper loading a trained adapter onto a base model to produce a standalone model (Ch 10)
**Perplexity** — Measure of how well a model predicts a text sample; lower is better (Ch 3, 11)
**Plan-and-Execute Agent** — Agent that builds a plan of actions first, then executes it; suited to long-horizon goals (Ch 9)
**PPO (Proximal Policy Optimization)** — RL algorithm used in RLHF to update the model toward higher reward (Ch 10)
**Product Quantization** — Splitting vectors into sub-vectors and replacing each with a k-means centroid index (Ch 11)
**PromptTemplate** — LangChain blueprint pairing `input_variables` with a template string (Ch 5, 6)
**PydanticOutputParser** — Parser defining output as a Pydantic model, with typed fields and `@validator` support (Ch 6)
**QLoRA** — LoRA over a frozen 4-bit-quantized base; 65B parameters on a 48GB GPU at bf16-equivalent quality (Ch 10, 11)
**Quantile Quantization** — Binning so each bin holds an equal number of input values; suits normal distributions (Ch 11)
**Quantization** — Reducing numerical precision of weights and/or activations to cut memory and latency (Ch 10, 11)
**Query Construction** — Translating a natural-language query into the target store's query language (SQL, Cypher, metadata filters) (Ch 8)
**Query Engine** — LlamaIndex interface processing a query into a response via retrievers and a response synthesizer (Ch 8)
**Query Expansion** — Adding synonyms and related terms to broaden a too-specific query (Ch 8)
**Query Transformation** — Restructuring a query for better search performance (Ch 8)
**QueryEngineTool** — LlamaIndex wrapper exposing a query engine to an agent, with `ToolMetadata` name and description (Ch 8, 9)
**Ragas** — Community evaluation library: faithfulness, answer relevancy, context precision, context recall, harmfulness (Ch 8)
**RAG (Retrieval-Augmented Generation)** — Adding a retrieval step before generation so the model answers from supplied evidence (Ch 7)
**ReAct** — Reasoning and Acting framework (Yao et al. 2022): the agent loop of thought → action → observation (Ch 9)
**Reasoning Engine** — Using an LLM to gather, process, and synthesize information rather than generate new content (Ch 9)
**Recursive Retrieval** — Navigating a graph of interconnected nodes; suits hierarchical documents with tables and references (Ch 8)
**RecursiveCharacterTextSplitter** — Splitter cascading through `["\n\n","\n"," ",""]` to preserve structure (Ch 7)
**refine** — Chain type iteratively enriching a running summary with each subsequent chunk (Ch 7)
**Reranking** — Re-scoring and reordering retrieved results to concentrate relevance before generation (Ch 8)
**ResponseSchema** — Field definition used with `StructuredOutputParser` (Ch 6)
**ReST (Reinforced Self-Training)** — DeepMind method alternating a Grow phase (generate data) and an Improve phase (rank, filter, fine-tune offline) (Ch 10)
**RetrieverEvaluator** — LlamaIndex class computing MRR and Hit Rate over an evaluation dataset (Ch 8)
**RetrievalQA** — LangChain chain combining a retriever with an LLM for question answering (Ch 7)
**Retriever** — Component exposing `get_relevant_documents(query)` over an index (Ch 7)
**RetryWithErrorOutputParser** — Repair parser seeing both the malformed output and the original prompt; recovers missing structure (Ch 6)
**Reward Model** — Classifier trained on human preference pairs, scoring completions during RLHF (Ch 10)
**RLAIF** — Reinforcement Learning from AI Feedback: a constitution-guided AI Feedback Model replaces human rankers (Ch 10)
**RLHF** — Reinforcement Learning from Human Feedback: rank completions, train a reward model, optimize with PPO under a KL penalty (Ch 3, 10)
**Salient Weights** — The 0.1–1% of weight channels with the largest activations, protected by AWQ (Ch 11)
**Scalar Quantization** — Per-dimension min/max binning into uniform intervals (Ch 11)
**SeleniumURLLoader** — Loader for JS-rendered pages; boots a browser per URL, so slow (Ch 7)
**SemanticSimilarityExampleSelector** — Selector retrieving the k nearest examples by embedding similarity (Ch 6)
**Sentence Window Retrieval** — Chunking to single sentences, each carrying a window of neighbors restored at retrieval (Ch 8)
**SFT (Supervised Fine-Tuning)** — Training on demonstration data of prompts and desired responses (Ch 10)
**SFTTrainer** — TRL trainer combining model, args, dataset, and LoRA config, with `packing` support (Ch 10)
**Small-to-Big Retrieval** — Match on a small precise unit, then hand the model the larger surrounding text (Ch 8)
**SparseGPT** — One-shot pruning of massive GPT models: ≥50% reduction, 60% unstructured sparsity, no retraining (Ch 11)
**Sparsity** — Reducing computation by removing redundant weights or activations (Ch 11)
**SSA (Sensibleness and Specificity Average)** — Google metric for open-domain chatbots: coherence plus directness (Ch 8)
**Static Quantization** — Quantization applied to weights before deployment (Ch 11)
**stuff** — Simplest chain type: insert all retrieved documents into one prompt (Ch 7)
**StructuredOutputParser** — Oldest LangChain parser; text-only, no validation, superseded (Ch 6)
**SubQuestionQueryEngine** — LlamaIndex engine decomposing a complex question into sub-questions and synthesizing the answers (Ch 8)
**Task Specifier Agent** — CAMEL component turning a vague human intent into a concrete task (Ch 9)
**Temperature** — Sampling parameter controlling output randomness; 0 for deterministic, higher for creative (Ch 3, 6)
**text-embedding-ada-002** — OpenAI embedding model used throughout the book; 1536 dimensions (Ch 6, 7)
**TimeWeightedVectorStoreRetriever** — LangChain retriever combining recency, relevance, and importance, tracking last-accessed time (Ch 9)
**TokenTextSplitter** — Splitter respecting BPE token boundaries; needs tiktoken, costs encode/decode compute (Ch 7)
**Tool** — Function an agent can invoke, described so the agent can decide when to use it (Ch 9)
**TRL** — Hugging Face library providing SFTTrainer, RewardTrainer, PPOTrainer (Ch 10)
**Unstructured Pruning** — Magnitude-based removal of individual weights, any sparsity pattern; needs special hardware for speedups (Ch 11)
**Structured Pruning** — Removal of whole channels/neurons; hardware-independent gains, lower compression (Ch 11)
**Validator** — Pydantic decorator function that rejects or repairs a parsed field (Ch 6)
**Vector Store** — Database optimized for storing and searching high-dimensional vectors (Ch 5, 7)
**VectorIndexRetriever** — LlamaIndex retriever returning top-k most similar nodes; precision-oriented (Ch 8)
**SummaryIndexRetriever** — LlamaIndex retriever returning all related nodes unranked; overview-oriented (Ch 8)
**vLLM** — Serving library with LLM-specific optimization, request batching, and memory management (Ch 11)
**Wanda** — LLM pruning by weight magnitude × input activation, per output; no retraining required (Ch 11)
**Whisper** — OpenAI speech recognition model trained on 680,000 hours of multilingual audio; sizes tiny→large (Ch 7)
