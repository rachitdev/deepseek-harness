# Chapter 2 — The Notes

## Core Idea
The twelve note names are the alphabet of the whole book: without them "scales, keys, modes,
chords and so on" cannot be understood, and you cannot tell which key of a sampler a sound sits
on. Hewitt teaches note names *from the physical keyboard pattern outward*, not from the staff:
find C, count the musical alphabet, then name the black keys as sharps and flats of what you
already know.

## Frameworks Introduced

### The Locate-C Procedure
1. **Locate C** as the white key immediately to the **left of any group of two black keys**.
2. **Count forward** through the musical alphabet for each white key: C D E F G A B, then back to A.
3. Then the harder drill: **count backward** in the musical alphabet going down from C.

Depending on keyboard range there are up to about seven Cs — the same note in different octaves.

### The Musical Alphabet
Only seven letters: **A B C D E F G**. On reaching G you return to A. The seven letters map
exactly onto the seven white keys of an octave.

### Naming the Black Keys
- From D, go **up** to the nearest black key → slightly higher (sharper) → **D sharp (D#)**.
- From D, go **down** to the nearest black key → slightly flatter → **D flat (Db)**.
- Every white-key note can be sharpened or flattened this way; that is how the black keys get
  their names.
- On the staff the sharp or flat sign is written **before** the note it affects.

### Enharmonic Equivalence
Each black key has two names depending on whether it is read as the sharp of the white key below
or the flat of the white key above. C# and Db are the same key. Notes related this way are
**enharmonic equivalents**; "the difference lies in the context in which the note is used" —
which only becomes fully clear once keys are studied.

### Octave Numbering
- Notes an octave apart are named by the same letter **because their frequency ratio is 2:1** —
  the upper note simply reinforces the second harmonic of the lower. "This connection that the
  ear recognizes between the two notes is the strongest one known in musical harmony."
- A number distinguishes the octave: the main point of reference is **C3 = Middle C**; all notes
  above carry the same number until C4.
- Convention: the upper number of a frequency ratio is written first (2:1).
- Practical payoff: "you only need to learn the names of the notes in one octave."

## Key Concepts
- **Octave** — from the word for eight; from note C you reach the next C after eight white keys.
- **Sharp (#)** — raises a note; **flat (b)** — lowers a note.
- **Root note of a sample** — when a sample is assigned to a particular keyboard note, that note
  is its root note. In generalized sampling (vocal phrases, natural sounds, drum hits) the sample
  sounds at its own natural pitch regardless of the key it is assigned to; in multi-sampled
  instruments (pianos, organs) D#4 is expected to actually produce D#4.
- **Event editor** — e.g. Cakewalk SONAR's; events are listed by the note names learned here, so
  knowing them gives "an immediate ability to recognize and edit each event."

## Mental Models
- **The keyboard is a pattern, not a list.** Black keys come in groups of two and three; between
  some white keys there is a black key and between others there is not. Grasping this pattern is
  the first step to identifying any note.
- **Cross-instrument consistency.** "Note D#4 on one synth will correspond to note D#4 on
  another" — note names are the interchange format between your gear.
- **Same name = same function an octave away.** Two notes an octave apart are heard "as being
  virtually identical."

## Anti-patterns
- Memorizing note positions on the staff before knowing them on the keyboard.
- Thinking C# and Db are different pitches — they are the same key, differently spelled.
- Assigning samples without knowing note names: "if the open hi-hats are assigned to note A#2,
  you need to know where A#2 is."

## Worked Example
**Exercise 4:** "The ratio between two notes an octave apart is ___ : ___. If the frequency of
the first note is given as 336 Hz, the frequency of the note an octave above will be ___."

Worked from the chapter's own statement that the octave is a 2:1 ratio and that the upper number
is written first:
- Ratio = **2 : 1**
- 336 Hz × 2 = **672 Hz**

The chapter's own parallel case: fundamental 220 Hz (A below Middle C) → second harmonic
440 Hz (A above Middle C), heard an octave higher; and C3 → C4 with double the frequency.

**Exercise 7:** "The first black key to the right of note D is called ___, while the first black
key to the left of note E is called ___. Because these are the same key but spelled differently,
they are classed as being ___ equivalents." From the chapter: **D#**, **Eb**, **enharmonic**.

## Key Takeaways
1. C is always the white key left of the two black keys — that single landmark unlocks the whole keyboard.
2. Seven letters, A–G, cycling; five black keys, each with two enharmonic names.
3. Octave numbering (Middle C = C3) means you only ever memorize one octave.
4. The 2:1 frequency ratio is *why* octave notes share a name — the strongest relationship in harmony.
5. Note names are the shared vocabulary between piano roll, event editor, sampler key map, and score.
