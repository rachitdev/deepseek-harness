# Cheatsheet — Quick and Easy Music Theory (Lloyd Steiner, 2009)

## The twelve notes

```
sharps:  A  A#  B  C  C#  D  D#  E  F  F#  G  G#
flats:   A  Bb  B  C  Db  D  Eb  E  F  Gb  G  Ab
```
Half-step letter pairs (no black key between): **E–F** and **B–C**. All others are whole
steps. One fret = one half step.

---

## Scale formulas

| Scale | Pattern |
|-------|---------|
| Major | W W H W W W H |
| Natural minor | W H W W H W W |
| Melodic minor ascending | W H W W W W H |
| Melodic minor descending | W H W W H W W (= natural minor) |
| Harmonic minor | *(book gives no separate scale pattern — see Scope note)* |

### The five rules for building scales
1. Use every letter of the musical alphabet.
2. All letters in order.
3. No repeated letters except the starting note.
4. Sharps in the scale → no flats.
5. Flats in the scale → no sharps.

## Diatonic triad patterns

| Mode | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|------|---|---|---|---|---|---|---|
| Major | I | ii | iii | IV | V | vi | viiº |
| Natural minor | i | iiº | III | iv | v | VI | VII |
| Harmonic minor | i | iiº | III | iv | **V** | VI | VII |

**Degree names** (same in every mode): 1 Tonic · 2 Supertonic · 3 Mediant ·
4 Subdominant · 5 Dominant · 6 Submediant · 7 Subtonic.

**Case convention:** UPPERCASE = major · lowercase = minor · lowercase + º = diminished.

No naturally occurring augmented chords in major or natural minor.

## Notation lookup

### Chord abbreviations
| Suffix | Meaning |
|--------|---------|
| *(none)* | Major |
| `m` | Minor |
| `dim` or `º` | Diminished |
| `aug` or `+` | Augmented |
| `7` | **Dominant** seventh |
| `maj7` | Major seventh |
| `sus2` / `sus4` / `sus6` | Suspended |
| `/X` | Inverted — X is the bass note |

### Inversions
| Bass note | Inversion | Figured bass | Abbreviation |
|-----------|-----------|--------------|--------------|
| Root (1) | Root position | `I` | `C` |
| Third (3) | First | `I6` | `C/E` |
| Fifth (5) | Second | `I64` | `C/G` |

### Figured bass
Format: `Key: numeral numeral numeral …`. **No key = no meaning.** Numerals transpose;
chord letters must be rewritten.

## Cadences

| Cadence | Formula | Use |
|---------|---------|-----|
| Authentic | V → I | Strongest ending; most used in history |
| Plagal | IV → I | "Amen cadence"; hymn ending |
| Deceptive | V → vi | Fake ending, used mid-song |

Start beginner compositions on **I** to establish tonality.

## Decision tables

### Which spelling — sharp or flat?
| Situation | Decision |
|-----------|----------|
| Inside a scale, other accidentals are flats | Flat (rule 5) |
| Inside a scale, other accidentals are sharps | Sharp (rule 4) |
| The letter is already used in the chord | Use the other letter |
| The alphabet check demands letter X | Whatever accidental makes X hit the counted pitch — including bb, x, Cb, Fb, B#, E# |

### Which notation should I write in?
| Situation | Use |
|-----------|-----|
| Both players know all scales and diatonic triads | Figured bass |
| You need to transpose the progression later | Figured bass |
| Mixed-experience band, no key agreed | Chord abbreviations |
| You need to specify inversions concisely | Either — `V6` or `G/B` |
| Orchestra or chamber group | Sheet music (Ch 2) |
| Never | Spelling every chord out longhand |

### Which minor scale?
| Need | Scale |
|------|-------|
| Baseline minor sound, no strong ending | Natural minor |
| A real tension-and-resolution ending in minor | Harmonic minor (most widely used) |
| A specifically ascending melodic line | Melodic minor ascending |
| Descending line in a melodic-minor piece | Natural minor pattern |

## Tells and smells (symptom → diagnosis → fix)

| Symptom | Diagnosis | Fix |
|---------|-----------|-----|
| A letter of the alphabet is missing from your scale | Rule 1 violated — you picked the wrong enharmonic | Re-spell the offending note to the missing letter |
| Two notes share a letter (C and C#) | Rule 3 violated | Re-spell one of them |
| The scale mixes # and b | Rules 4/5 violated | Pick one accidental type and re-spell |
| Scale ends on a different letter than it started | Miscounted an interval | Re-walk the formula from slot 1 |
| Your chord "sounds right" but has the wrong letters (F Ab B) | You re-spelled the chord instead of the note | Change B to Cb — the chord's letters are fixed by the alphabet check |
| Someone says "play a D chord" | They omitted the quality | Ask major or minor; never say it yourself |
| Your progression uses a chord not in the seven | Out of key | Replace with a diatonic chord, or change key |
| Minor progression's ending feels weak | v is minor | Raise the third of V — switch to harmonic minor |
| Your hand jumps around the keyboard between chords | All root position | Invert to hold common tones (Ch 26) |
| Listener's ear "jumps around in confusion" | Same cause | Same fix |
| Singer sounds sour | Singing a note not in the current chord | Restrict to chord tones |
| Song ends and the audience doesn't know to applaud | No recognisable cadence | End V → I or IV → I |
| Chord abbreviation has a `7` and you played a major seventh | `7` means dominant | Use `maj7` for a major seventh |
| Roman numerals mean nothing to the reader | Key not stated | State the key |

## Process templates

### Build any scale
```
1. Write the W/H formula.
2. Root → slot 1.
3. Walk one interval at a time; decide each black key by rules 1–5.
4. Confirm slot 8 = slot 1.
5. Run the five-rule checklist.
```

### Build any chord
```
1. Write the letters from the root; number 1–5 (triad) or 1–7 (seventh).
2. Read off the slots the formula uses — those letters are now locked.
3. Count the first interval from the root.
4. Count each later interval from the PREVIOUS note.
5. Attach whatever accidental makes each locked letter hit the counted pitch.
```

### Harmonise a key
```
1. Write the seven scale notes.
2. Renumber with each note as slot 1 in turn.
3. Read slots 3 and 5.
4. Name the triad; assign the numeral by case (+ º if diminished).
5. Sanity-check against the mode's positional pattern.
```

### Write a song without an instrument
```
1. Pick a key.
2. Harmonise it → seven chords.
3. Choose 6+ of them in an order; start on I.
4. End with an authentic or plagal cadence.
5. Arrange: hold common tones, move to the nearest letter.
6. Assign parts — bass first (it fixes the inversions), then everyone else
   using any notes in the chord.
7. Play it.
```
